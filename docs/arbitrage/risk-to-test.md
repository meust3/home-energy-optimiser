# Candidate risk to verification map

| Risk | Executable witness / retained boundary |
|---|---|
| Frozen rule or kernel drift | original core SHA pin, 79 kernel cases and 82 selector cases, original policy SHA; original fixtures/actions unchanged |
| Hindsight changes selection | immutable receipts, future evidence/admission failures, evaluate recomputation before opening outcomes |
| Partial commit becomes available early | SQLite/PostgreSQL crash-between-transactions, retry upper bound, immutability/conflict rollback |
| Data-capture breaks collector | whitelist tests, existing cached states only; optional exception isolation; bounded 1s connect/500ms SQL; no retry |
| Coordinator replaces forecasting or fails core operation | enabled 288-point capture after success audit, capture-fault isolation and unchanged existing full suite |
| Baseline double counts EV or lacks total load | producer-shaped admission with explicit uncontrolled scenario; missing EV/units/provenance rejected |
| Terminal inventory manufactures profit | unmatched primary unavailable; new bounds diagnostic only; preserved kernel comparator |
| Sequence resets SOC / different actuals | own-state replay cash/energy checks, state-reset/gap/missing-input/profile/action/exogenous-path fault cases |
| Export exceeds shared/site/reserve envelopes | floor/saturation events, dynamic zero cap, PV/load priority, shared clipping, eta/signed prices, independent rational arithmetic |
| Export ignores later PV value | flat-price negative-benefit witness versus explicitly different future-price synthetic scenario |
| Hardware reachable through read path | GET-only API/Ingress access policy, no control endpoint, executor rejects real/custom transport |
| ACK confused with delivered action | delayed/partial/unknown delivery, restarted SENT journal, no resend, fresh precheck fault matrix |
| Abort or failed restore unlocks next controller | durable competing-owner rejection until neutral; manual generation wins without restore |
| Secret / household data leakage | capture scalar/attribute whitelist, no credentials/trackers; private evidence ignored; source archive only |
| Destructive downgrade misrepresented | compatible disabled recovery retains new rows; old code rejects new head; physical downgrade explicitly destructive and unauthorised |
| Packaged files drift | exact committed git archive through actual Dockerfile, source/assets/entrypoint hashes, actual dependencies and image identity |
| Read-only dashboard misleading | local synthetic browser QA: awaiting, blocked, conditional and expired states; no apparent executable controls |

Fault rehearsals are local and synthetic. Host/HA/database/network-loss fakes do
not prove physical power-loss behavior or finite installed-device expiry.
Actual Gate B needs the named equipment/firmware, metering, binding cap,
controller handover and a separately approved per-action test with human fallback.
